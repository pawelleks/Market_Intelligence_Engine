# Seasonality Analysis Reference
*Status: Stable, Implemented in React/FastAPI Hybrid Architecture*

This module provides time-series pattern analysis by aggregating historical daily returns by calendar day and trading day of the year (TDOY). It is designed to be highly configurable via API parameters.

---

## 1. Data Contract & Calculation Source

| Data Source | Location | Purpose |
| :--- | :--- | :--- |
| **Input (Raw)** | `data/raw/{TICKER}.parquet` | Used by `seasonality_engine.py` to calculate returns and TDOY. |
| **Output (Base)** | `data/seasonality/base/{TICKER}.parquet` | Pre-aggregated daily returns (`r`, `lr`) enriched with `month`, `day`, and `tdoy`. |

**Core Calculation Logic:** TDOY is calculated as the cumulative count of trading days within a specific year. Seasonal curves are generated by averaging the daily returns across all years in the lookback window and then calculating the cumulative sum of that average path.

## 2. API Endpoints

All endpoints use the `lookback` query parameter to filter the historical data.

### 2.1 GET /api/v1/seasonality/curves/{ticker}
* **Function:** `get_seasonal_curves`
* **Purpose:** Provides the data for the "Seasonality vs Actual" chart (Current Year Path vs. Historical Average Paths).
* **Query Params:** `lookbacks` (string of comma-separated years, e.g., '10,20').
* **Returns:** Array of objects containing `label` and daily returns (`r`) aligned by `tdoy`.

### 2.2 GET /api/v1/seasonality/heatmap/{ticker}
* **Function:** `get_calendar_heatmap`
* **Purpose:** Provides the 12x31 matrix of average returns for the Calendar Heatmap.
* **Query Params:** `lookback` (int).
* **Returns:** Array of objects: `[{ "month": X, "day": Y, "value": Avg_Return_Percent }]`.

### 2.3 GET /api/v1/seasonality/drilldown/{ticker}/{month}/{day}
* **Function:** `get_day_drilldown`
* **Purpose:** Provides statistics (Mean Return, Win Rate) and historical records for a specific calendar day.
* **Returns:** Object including `stats` (summary) and `records` (historical daily returns).
