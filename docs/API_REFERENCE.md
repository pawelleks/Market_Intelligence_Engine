# API Reference - Market Intelligence Engine

**Last Updated**: 2026-02-12  
**Authority**: Shotgun Audit (`.shotgun/research/api-endpoint-analysis.md`)

## Overview

This document provides a comprehensive reference for all API endpoints in the Market Intelligence Engine. Each endpoint is classified by mode (BATCH, REAL-TIME, or HYBRID) and includes complete parameter documentation.

**Base URL**: `https://blindmonkey.io/api/v1` (production) or `http://localhost:8000/api/v1` (local)

---

## Classification System

| Mode | Description | Response Time | Use Case |
|------|-------------|---------------|----------|
| **BATCH** | Pre-computed data served from disk | <100ms | Historical analysis, dashboards |
| **REAL-TIME** | On-demand calculation per request | 1-5s | Live market data, intraday updates |
| **HYBRID** | Cache-first with fallback to calculation | <100ms (cached) / 1-5s (calc) | Balance between speed and freshness |

### GET /expected_moves/theta/latest/{ticker}
**Mode**: REAL-TIME ⚡  
**Description**: Live Expected Moves calculation from ThetaData REST API  
**Response Time**: 2-5 seconds

**Path Parameters**:
- `ticker` (string, required): Ticker symbol (e.g., "SPY", "SPX", "QQQ")

**Data Source**: ThetaData REST API (port 25510) - live calculation

**Calculation Flow**:
1. Fetch spot price via `/v2/hist/stock/eod` or `/v2/hist/index/eod`
2. Determine expirations (0DTE, WEEKLY, MONTHLY)
3. For each expiration, fetch ATM straddle via `/v2/bulk_snapshot/option/quote`
4. Apply bad tick filter + estimation
5. Calculate `EM = straddle_price × 0.85` (sigma factor)

**Response Schema**:
```json
{
  "ticker": "SPY",
  "spot_price": 450.12,
  "0DTE": {
    "expected_move": 8.45,
    "high": 458.57,
    "low": 441.67,
    "plus_minus": 8.45,
    "expiration": "2026-02-12",
    "debug": {
      "straddle_price": 9.94,
      "sigma_factor": 0.85,
      "bad_ticks_filtered": 2
    }
  },
  ...
}
```

**When to Use**:
- Real-time intraday updates during market hours
- Independent verification of batch calculations
- When Massive CSV data is not yet available

**Setup Requirements**:
- ThetaData Terminal must be running (container: `mie-theta`)
- Environment variables: `THETA_HOST`, `THETA_REST_PORT`

## Gamma Exposure (GEX) Endpoints

### GET /gex/latest/{ticker}
**Mode**: HYBRID 🔄  
**Description**: Latest GEX data with intelligent caching  
**Response Time**: <50ms (cached) / 1-3s (on-demand calculation)

**Path Parameters**:
- `ticker` (string, required): Ticker symbol (e.g., "SPY")

**Query Parameters**:
- `force_refresh` (boolean, optional, default: false): **Bypass cache and trigger live calculation**

> [!IMPORTANT]
> **Hidden Parameter**: `force_refresh=true` is not advertised in the UI but is available for advanced users who need guaranteed fresh data.

**Cache Strategy**:
```
Request → Memory Cache (15-min TTL)
              ↓ miss
          Disk (Daily Build JSON)
              ↓ miss or force_refresh=true
          On-Demand Calculation (GEXEngine)
```

**Data Sources**:
- Cache/Disk: `data/analytics/gex/{TICKER}_profile_latest.json`
- On-demand: Fetches live option chain from Polygon/Massive

**Response Schema**:
```json
{
  "ticker": "SPY",
  "spot_price": 450.12,
  "timestamp": "2026-02-12T10:30:00",
  "profile": [
    {
      "strike": 450.0,
      "net_gex": 1234567.89,
      "call_gex": 2000000.00,
      "put_gex": -765432.11,
      "total_oi": 50000
    },
    ...
  ],
  "summary": {
    "max_gex_strike": 450.0,
    "max_gex_value": 1234567.89,
    "zero_gex_strike": 448.5,
    "total_net_gex": 5000000.00
  }
}
```

**Examples**:
```bash
# Cached/disk data (fast)
curl https://blindmonkey.io/api/v1/gex/latest/SPY

# Force live calculation (slow but fresh)
curl https://blindmonkey.io/api/v1/gex/latest/SPY?force_refresh=true
```

## Error Responses

All endpoints follow standard HTTP status codes:

| Status Code | Meaning | Example |
|-------------|---------|---------|
| 200 | Success | Data returned successfully |
| 404 | Not Found | Ticker data not available or file missing |
| 500 | Server Error | Calculation failed or external API error |
| 503 | Service Unavailable | ThetaData Terminal not running |

**Error Response Schema**:
```json
{
  "detail": "Error message describing what went wrong"
}
```

## Rate Limiting

- **Batch endpoints**: No rate limiting (served from disk)
- **Real-time endpoints**: Limited by external API rate limits
  - ThetaData: ~10 requests/second
  - Polygon: Varies by subscription tier

---

## Best Practices

1. **Use batch endpoints for dashboards**: They're fast and don't consume API quota
2. **Use real-time endpoints sparingly**: Only when you need guaranteed fresh data
3. **Leverage caching**: GEX endpoints have intelligent caching; don't use `force_refresh` unless necessary
4. **Check data freshness**: Batch data is updated daily at 22:00 UTC
5. **Handle errors gracefully**: Real-time endpoints can fail if external APIs are down
